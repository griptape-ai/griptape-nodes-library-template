# Example Library

A small library of example nodes for learning how Griptape Nodes libraries work. Copy it to start your own, then swap in your nodes and these docs.

The nodes show the patterns you'll reach for most: a node that cleans up what you type, a node that builds a sentence, a slider, custom widgets, and pairs of strict-mode nodes where one breaks a rule and the other follows it.

## Start here

- [Getting started](guides/getting-started.md) builds a small workflow from three of the nodes.
- Open the **Introduce Yourself in Pig Latin** template to see that workflow finished, or drag in the **Introduce Yourself** node to get the same result in a single node.
- [Writing docs for your own library](guides/writing-your-own-docs.md) explains how this `docs/` folder is laid out and what each folder is for.

## Finding a node

The editor lists this library's nodes by category: **ControlNodes**, **DataNodes**, and **StrictModeNodes**. Nodes with a page here open it. The rest show a short page built from their description and parameters.
