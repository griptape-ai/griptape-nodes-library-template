## When to use it

You have a name and an age, and want a sentence like "Hey! My name is Maria Lopez, and I'm 34 years old." The text is built the same way every time, so it works as a predictable input for nodes that follow.

## Example

[Getting started](../../guides/getting-started.md) builds this introduction step by step. [Introduce Yourself](../../workflow_nodes/IntroduceYourself.md) wraps the same steps in one node.

## Parameters

### full_name

The name to introduce. Connect it from [Create a Name](../CreateName.md), or type one in.

### age

A whole number.

### introduction

The finished sentence. It's the output to connect onward.
